業務連絡

文面をコピーして手動送信、または登録済みのLINEへ宛先・全文を確認して送信できます。定時・自動送信はしません。

作業予定を追加・編集

参加する作業予定の組合せが同じ連絡対象者をまとめ、１日分の連絡文を作ります。家族は予定編集で連絡対象に選んだ場合のみ表示します。コピーでは予定を変更せず、連絡時点の全予定・文面の控えを保存します。コピーはLINE送信を意味しません。

追加先のカードをクリックして選択してください。選択した文面の「よろしくお願いします。」の直前に追加します。結びを変更・削除した文面には末尾に追加します。

追加は文面だけに反映します。コピーまたはLINE送信準備をするまでは保存されず、日付変更・再読み込みで消えます。送信準備した文面は下のLINE送信履歴に残ります。

LINE登録・承認・この日の送信履歴

LINE連携の初回設定後に利用できます。未設定・エラーでもコピーは使えます。返信は公式アカウント管理アプリで対応してください。

登録状態は未取得です。

作業者（パート・家族）の登録

登録コードを対象の本人へ個別に渡します。本人が公式アカウントへ送信した後、LINE表示名を本人に確認して承認してください。表示名だけでは自動で紐づけません。

コードは秘密扱いです。本人以外への共有・画面画像の投稿はしないでください。発行し直すと旧コードは無効になります。

選択日の送信履歴・未完了の送信

受付済みは配達・既読の保証ではありません。結果不明時は新規送信を作らず、同じ履歴から再試行してください（最初の試行から23時間以内）。

{年}・{月}・{先月}・{来月}・{翌月5日}（曜日付き）は今日の日付から自動で置き換えています。コピーしてLINEへ貼り付けてください。
