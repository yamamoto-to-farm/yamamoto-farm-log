文面を作ってコピーし、LINEに貼り付けて送る運用です（このページから自動送信はしません）。

作業予定を追加・編集

参加する作業予定の組合せが同じパートをまとめ、１日分の連絡文を作ります。コピーでは予定を変更せず、連絡時点の全予定・文面の控えを保存します。コピーはLINE送信を意味しません。

追加先のカードをクリックして選択してください。選択した文面の「よろしくお願いします。」の直前に追加します。結びを変更・削除した文面には末尾に追加します。

追加は文面だけに反映します。コピーするまでは控えに保存されず、日付変更・再読み込みで消えます。

{年}・{月}・{先月}・{来月}・{翌月5日}（曜日付き）は今日の日付から自動で置き換えています。コピーしてLINEへ貼り付けてください。
